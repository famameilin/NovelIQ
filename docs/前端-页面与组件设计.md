**布局架构**：
- **左右布局**：左侧固定宽度 `w-96`（384px），右侧 `flex-1` 自适应
- **响应式网格**：右侧卡片网格根据屏幕宽度自适应
  - `sm`: 3 列
  - `lg`: 4 列
  - `xl`: 5 列
- **左侧渐变背景**：从 `primary/10` 到 `chart-2/5`，带装饰性模糊圆形元素

**组件拆分**：

| 组件 | 说明 |
|------|------|
| `HeroSection` | 左侧标题 + 副标题 + 统计卡片 + 上传按钮（已集成到 HomePage 内部） |
| `NovelCard` | 单张小说卡片，显示书名、作者、文件大小、状态、时间 |
| `UploadDialog` | 上传确认弹窗 |
| `AnalysisProgressRing` | 环形进度指示器，嵌在 NovelCard 中 |

**NovelCard 详细设计**：
```
┌──────────────────┐
│  封面区域 (75%)   │  ← 左侧主题色装饰条（w-1.5）
│                  │  ← 空白封面：渐变背景 + 装饰几何 + 图标 + 标题
│                  │  ← 有封面：图片
│                  │  ← 分析中：进度环遮罩
├──────────────────┤
│  底部信息栏 (25%) │
│  标题             │
│  作者 · 文件大小  │
│  [状态徽章] 时间  │
└──────────────────┘
```

**卡片视觉特性**：
- **比例**：`aspect-[2/3]`（书籍标准比例 2:3）
- **封面区域**（75%）：
  - 左侧装饰条：`w-1.5`，颜色跟随 `themeColor`
  - 有封面图：显示 `/api/novels/{id}/cover`
  - 无封面图：渐变背景 + 装饰圆形/方块 + 64px 图标 + 标题
  - 分析中：半透明遮罩 + 进度环 + 状态文字
- **底部信息栏**（25%）：
  - 标题：`text-sm font-semibold`
  - 次要信息：`text-[10px]`（作者 · 文件大小）
  - 状态徽章 + 时间

**交互细节**：
- 点击 `NovelCard` → 跳转到小说仪表盘页
- 卡片悬浮：微上浮（`translateY(-4px)`）+ 阴影加深
- 上传通过顶部按钮触发 `UploadDialog`
- 分析进行中的卡片显示环形进度，通过轮询 `status` 接口更新

**数据依赖**：
- `GET /api/novels/` → 小说列表
- `POST /api/novels/upload` → 上传
- `POST /api/novels/{id}/analyze` → 启动分析
- `GET /api/novels/{id}/status` → 轮询进度

**组件拆分**：

| 组件 | 说明 |
|------|------|
| `NovelHeader` | 书名 + 任务选择下拉 + 状态标签 + 操作按钮（重新分析/删除） |

| `ScoreOverviewCard` | 评分速览：伏笔兑现率（迷你环形进度）+ 三个 0-5 圆点评分条（权力立场/平民尊严/文化深度），底部链接到 DiagnosisPage |
| `DimensionMiniCard` | 五维速览卡片（通用），每张卡展示 1-2 个 A类原始值 + 专属微型可视化 + 可选页面链接 |

**五维速览卡片（DimensionMiniCard）可视化类型**：

每张卡片使用不同的微型可视化类型，避免视觉单调：

| 维度 | 展示指标 | 微型可视化 | 链接到 |
|------|---------|-----------|--------|
| 叙事结构 | `middle_collapse_index`（如 0.92） | 半圆仪表盘（Gauge），1.0 基准线，< 0.85 警告色 | TimelinePage |
| 情感基调 | `pos_neg_ratio`（如 1.35） | 正负对比双柱，正面/负面用 chart-positive / chart-negative 色 | CurvesPage |
| 人物网络 | `network_density`（如 0.12） | 迷你节点连线图（装饰性 SVG），节点数映射实际规模 | GraphPage |
| 语言风格 | `vocab_breadth` + `dialogue_ratio` | 双横向条形图，附数值标签 | — |
| 文化底色 | `idiom_density` + `classical_sentence_ratio` + `imagery_density` | 三指标细横条，附百分比数值 | — |

> **设计决策**：不再使用五维雷达图。原方案将五个维度各自的多个指标通过手工权重压缩为
> 单一 0-100 分数，存在以下问题：(1) 归一化权重无理论依据（参见指标手册 A/B 类分类）；
> (2) 每维度仅挑选 2-3 个指标，丢弃了大量信息；(3) 不同维度被放到同一尺度，暗示可比性
> 但实际不可比。新方案直接展示 A类原始值 + 参考含义，更诚实也更有信息量。

**可视化类型汇总（共 11 种）**：

| # | 类型 | 所在组件 | 技术实现 |
|---|------|---------|---------|
| 1 | Badge 标签 | DiagnosisSummaryCard | shadcn Badge |
| 2 | Badge 标签组 | DiagnosisSummaryCard（主题标签） | shadcn Badge × N |
| 3 | 文字标签 + 图标 | DiagnosisSummaryCard（主角/价值逻辑） | Typography + Lucide icon |
| 4 | 迷你环形进度 | ScoreOverviewCard（伏笔兑现率） | SVG circle + stroke-dasharray |
| 5 | 圆点评分条 | ScoreOverviewCard（0-5 分三项） | 5 个 SVG circle，填充/空心切换 |
| 6 | 半圆仪表盘 | DimensionMiniCard · 叙事结构 | ECharts gauge 或自定义 SVG |
| 7 | 正负对比双柱 | DimensionMiniCard · 情感基调 | ECharts bar 或自定义 SVG |
| 8 | 迷你节点连线 | DimensionMiniCard · 人物网络 | 自定义 SVG（装饰性） |
| 9 | 横向条形图 | DimensionMiniCard · 语言风格 | 自定义 CSS bar |
| 10 | 分段进度条 | NarrativeStructureBar（三幕比例） | SegmentedBar 组件（已有） |
| 11 | 折线图缩略 | MiniCurvePreview（情绪曲线） | ECharts line（已有） |

**动画设计**：
- 卡片交错入场：Framer Motion `staggerChildren: 0.08`
- 数字递增：`useCountUp` hook（伏笔率百分比、密度值）
- 环形进度展开：stroke-dashoffset 过渡动画
- 仪表盘指针旋转：CSS transition / ECharts 内置动画
- 卡片悬浮：微上浮（`translateY(-4px)`）+ 阴影加深 + 链接提示显现

**交互细节**：
- 任务选择器切换时，所有数据刷新（TanStack Query 自动处理）
- DiagnosisSummaryCard 底部可点击跳转到 DiagnosisPage
- ScoreOverviewCard 底部可点击跳转到 DiagnosisPage
- 五维速览卡片悬浮显示指标含义 Tooltip（引用指标手册中的高低值含义）
- 带链接的卡片悬浮时显示 "→ 查看详情" 提示
- NarrativeStructureBar 点击跳转到 TimelinePage
- MiniCurvePreview 点击跳转到 CurvesPage

**数据依赖**：
- `GET /api/novels/{id}/tasks` → 任务列表（填充 TaskSelector）
- `GET /api/novels/{id}/diagnosis?task_id=` → 诊断画像 + 评分速览数据
- `GET /api/novels/{id}/metrics/narrative-structure?task_id=` → 三幕比例 + 事件密度 + 中段塌陷指数
- `GET /api/novels/{id}/metrics/emotion-stats?task_id=` → 正负词汇比
- `GET /api/novels/{id}/metrics/character-stats?task_id=` → 网络密度
- `GET /api/novels/{id}/metrics/style-stats?task_id=` → 词频广度 + 对话占比
- `GET /api/novels/{id}/metrics/culture-stats?task_id=` → 成语密度 + 古典句式比例 + 意象密度
- `GET /api/novels/{id}/chunk-curves?task_id=` → 曲线缩略预览

**"预告片 vs 正片"对照**：

仪表盘仅展示每个维度的摘要级可视化，各详情页展示完整交互式分析：

| 仪表盘（摘要） | 详情页（完整） |
|---------------|---------------|
| 伏笔率迷你环 60% | DiagnosisPage：ScoreCard + 评分条 + reason 文字说明 |
| ●●●○○ 评分 3/5（无 reason） | DiagnosisPage：完整 reason 文本 + 代表性段落 |
| 三幕分段条 25%/52%/23% | TimelinePage：完整时间轴 + 节点 + 张力叠加 + 事件详情面板 |
| 情绪 2 线缩略折线图 | CurvesPage：4 线交互图 + Brush 联动 + 高潮标注 + 三幕分界线 |
| 网络密度数字 + 装饰节点图 | GraphPage：全屏力导向图 + 拖拽 + 过滤 + 节点详情面板 |
| 正负词比对比双柱 | CurvesPage：完整情绪密度四曲线 + 情感极性分布 |

## 三、通用组件规范

### 3.1 组件分类

| 类别 | 目录 | 特征 |
|------|------|------|
| **UI 基础** | `components/ui/` | shadcn/ui 组件，纯展示，无业务逻辑 |
| **图表** | `components/charts/` | ECharts/ForceGraph 封装，接收数据和配置 |
| **时间轴** | `components/timeline/` | 自定义时间轴组件族 |
| **业务通用** | `components/common/` | 带业务语义但跨页面复用的组件 |
| **布局** | `components/layout/` | 页面布局骨架 |

### 3.2 组件接口原则

1. **数据通过 props 传入**：组件不直接调用 API
2. **状态通过回调上报**：`onSelect`, `onHover`, `onClick` 等
3. **加载/空/错误状态内置**：每个数据展示组件自带 skeleton/empty/error 三态
4. **尺寸自适应**：图表组件通过 `ResizeObserver` 自动适应容器
5. **动画可控**：通过 `animate` prop 控制是否启用进场动画（SSR 降级用）

### 3.3 加载状态设计

| 状态 | 表现 |
|------|------|
| **加载中** | Skeleton 骨架屏（保持布局占位，脉冲动画） |
| **空数据** | 居中图标 + "暂无数据" 文案 + 操作建议 |
| **请求失败** | 错误图标 + 错误信息 + "重试" 按钮 |
| **分析未完成** | 进度指示 + "分析进行中" 提示 |

## 四、设计语言规范

> **最后更新**: 2026-04-04  
> **定位**: 定义组件级视觉语言的统一标准，确保所有页面风格一致

### 4.1 设计原则

| 原则 | 说明 |
|------|------|
| **视觉优先** | 现代、柔和、有层次感，每个交互都有反馈 |
| **一书一色** | 组件跟随主题色变化，accent 系统支持多色共存 |
| **渐进增强** | default 变体简洁低调，elevated 变体增加层次与动效 |
| **组件复用优先** | 禁止用 `<div>` 手写卡片样式，统一通过组件 API 获得视觉效果 |

### 4.2 组件层级

| 层级 | 目录 | 说明 |
|------|------|------|
| **UI 基础层** | `components/ui/` | 纯展示、无业务语义（Card、Button、Badge、Table） |
| **业务组件层** | `components/common/` | 带业务语义、跨页面复用（DimensionMiniCard、ScoreOverviewCard、SegmentedBar、NovelCard） |

### 4.3 Card 设计规范

Card 是通用容器组件，通过 `cva` 管理两个 variant：

| 属性 | `default` | `elevated` |
|------|-----------|------------|
| 圆角 | 无 | 无 |
| 阴影 | `shadow-sm` | `shadow-sm` |
| 背景 | 继承（`bg-surface`） | 继承（`bg-surface`），可通过 className 叠加渐变 |
| 边框 | `border-border` | `border-border` |
| 过渡 | 无 | `transition-all duration-300` |
| hover 抬升 | 无 | `hover:-translate-y-1 hover:shadow-lg` |
| overflow | — | `overflow-hidden`（防止渐变溢出） |

**使用场景**：

- `default`：弹窗、下拉面板、表格外壳、标签页内容区等
- `elevated`：数据展示类内容区、需要悬浮交互反馈的卡片区域

**elevated 渐变用法**：通过 className 叠加，如 `bg-gradient-to-br from-surface via-surface to-chart-1/15`。

```tsx
// 默认卡片
<Card>...</Card>

// elevated 卡片 + 渐变
<Card variant="elevated" className="bg-gradient-to-br from-surface via-surface to-primary/15">
  <CardHeader>...</CardHeader>
  <CardContent>...</CardContent>
  <CardFooter>...</CardFooter>
</Card>
```

### 4.4 MetricCard 设计规范

> **废弃说明**：`MetricCard` 已从仪表盘（NovelDetailPage）移除，替代方案为 `DimensionMiniCard`、
> `ScoreOverviewCard`、`NarrativeStructureBar`（见 §2.2）。以下规范保留作为历史参考，
> 若未来其他页面需要类似指标卡可复用其 Accent 多色系统和底部插槽设计。

MetricCard 是指标展示专用卡片，默认使用 `Card variant="elevated"` 并在此基础上增加以下视觉语言：

#### 圆角

MetricCard 自带 `rounded-xl`（12px），与通用 Card 的无圆角区分。

#### Accent 多色系统

通过 `accent` prop 切换强调色系，影响渐变背景、图标色块、进度条渐变、hover 边框：

| accent 值 | 渐变尾色 | 图标色块 | 进度条渐变 | hover 边框 |
|-----------|---------|---------|-----------|-----------|
| `primary`（默认） | `to-primary/15` | `bg-primary/10 text-primary` | `from-primary to-primary-hover` | `border-primary/30` |
| `chart-1` | `to-chart-1/15` | `bg-chart-1/10 text-chart-1` | `from-chart-1 to-chart-2` | `border-chart-1/30` |
| `chart-2` | `to-chart-2/15` | `bg-chart-2/10 text-chart-2` | `from-chart-2 to-chart-3` | `border-chart-2/30` |
| `chart-3` | `to-chart-3/15` | `bg-chart-3/10 text-chart-3` | `from-chart-3 to-chart-4` | `border-chart-3/30` |
| `chart-4` | `to-chart-4/15` | `bg-chart-4/10 text-chart-4` | `from-chart-4 to-chart-5` | `border-chart-4/30` |
| `chart-5` | `to-chart-5/15` | `bg-chart-5/10 text-chart-5` | `from-chart-5 to-chart-1` | `border-chart-5/30` |

**渐变透明度**：统一使用 `/15`（15%），兼顾可视性和柔和感。

#### 图标色块

图标包裹在 `h-10 w-10 rounded-lg` 色块中，背景色为 accent 的 10% 透明度，文字色为 accent 原色。

#### 底部区域设计

MetricCard 的底部区域根据数据类型自动选择展示方式：

| 数据类型 | 底部元素 | 实现方式 |
|---------|---------|---------|
| `score` / `percent` | 渐变进度条 | 自动显示，宽度按比例计算 |
| `number` + `showBar` | 渐变进度条 | 手动开启，宽度 = `value`（上限 100%） |
| 可拆分指标（如三幕比例） | `SegmentedBar` | 通过 `footer` prop 传入 |
| 角色列表 | 头像堆叠 + 提示 | 通过 `footer` prop 传入 |

#### 其他 Props

| Prop | 类型 | 说明 |
|------|------|------|
| `trend` | `string` | 右上角趋势标签（如 `"+12%"`），带 `chart-positive` 色背景 |

| `footer` | `ReactNode` | 底部插槽（SegmentedBar、头像堆叠等） |
| `description` | `string` | 悬浮 Tooltip 说明（有进度条/footer 时） |

### 4.5 SegmentedBar 设计规范

SegmentedBar 用于展示可拆分的比例型指标（如三幕结构比例）。

**结构**：堆叠分段条 + 下方图例行

**分段条**：
- 高度：`h-1.5`（与 MetricCard 进度条一致）
- 每段宽度按 value 归一化
- 颜色通过 `colorClass` 传入，建议使用 `chart-*` 色系以保证深色下区分度

**图例行**：
- 布局：`flex justify-between w-full`（均匀分布在左/中/右）
- 色标：5x5 小方块 `rotate-45`（菱形），使用与分段条相同的 `bg-*` 类
- 文字：`text-[10px] text-text-muted`，格式 `{label} {value}%`

### 4.6 圆角规范

| 组件 | 圆角 | 说明 |
|------|------|------|
| Card（default / elevated） | 无 | 通用容器保持方正 |
| MetricCard（已废弃） | `rounded-xl`（12px） | 指标卡区分于通用容器 |
| DimensionMiniCard | `rounded-xl`（12px） | 继承 MetricCard 的圆角规范 |
| ScoreOverviewCard | `rounded-xl`（12px） | 评分速览卡片 |
| NarrativeStructureBar | `rounded-xl`（12px） | 叙事结构概览卡片 |
| DiagnosisSummaryCard | 无 | 信息容器，融入页面布局 |
| SegmentedBar 条形 | `rounded-full` | 两端圆角 |
| SegmentedBar 色标 | `rounded-[1px]` | 微圆角菱形 |
| Button | `rounded-md`（6px） | shadcn 默认 |
| Badge | `rounded-full` | 药丸形 |

### 4.7 动效规范

| 效果 | 参数 | 应用场景 |
|------|------|---------|
| hover 抬升 | `hover:-translate-y-1`（4px）+ `duration-300` | Card elevated、DimensionMiniCard、ScoreOverviewCard |
| hover 阴影 | `hover:shadow-lg` | Card elevated、DimensionMiniCard、ScoreOverviewCard |
| hover 边框 | `hover:border-{accent}/30` | DimensionMiniCard（跟随维度色） |
| 进度条填充 | `transition-all duration-500` | ScoreOverviewCard 环形进度、SegmentedBar、NarrativeStructureBar |

### 4.8 禁止事项

1. **禁止用 `<div>` 手写卡片样式**：必须使用 `<Card>` 或业务卡片组件（`DimensionMiniCard`、`ScoreOverviewCard` 等），确保视觉语言统一
2. **禁止在组件中硬编码颜色值**：使用 CSS 变量（`var(--primary)`）或 Tailwind 语义类（`bg-primary`）
3. **禁止使用 Tailwind 动态类名拼接**：如 `` `bg-${color}` `` 无法被 Tailwind 静态扫描，必须使用完整类名字符串

### 4.10 DimensionMiniCard 设计规范

```tsx
  novelId={novelId}
/>
```

### 4.14 DiagnosisSummaryCard 设计规范

DiagnosisSummaryCard 是诊断画像专用卡片，用于展示叙事类型、主角、价值逻辑等摘要信息。

#### 布局结构

```
┌────────────────────────────┐
│ 诊断画像                    │
│                            │
│ [叙事类型] [弧线类型]       │  ← Badge 组
│                            │
│ 👤 主角: 林天              │  ← 图标 + 文字
│ 🎯 价值逻辑: 善义有价值     │
│                            │
│ [修仙] [成长] [热血] ...   │  ← 主题标签组
│                            │
│ → 查看完整诊断报告          │  ← 链接按钮
└────────────────────────────┘
```

#### 视觉规范

| 元素 | 样式 | 说明 |
|------|------|------|
| 卡片容器 | `Card variant="elevated"` | **无圆角**，融入页面布局 |
| 标题 | `text-sm font-semibold text-text` | 标准标题样式 |
| Badge（叙事类型） | `variant="secondary"` | 实心背景 |
| Badge（弧线类型） | `variant="outline"` | 空心边框 |
| 图标 | `h-4 w-4 text-text-muted` | Lucide 图标，统一尺寸 |
| 主题标签 | `variant="secondary" text-[10px]` | 小号 Badge |
| 链接按钮 | `variant="ghost" size="sm"` | ghost 样式，悬浮显示主题色 |

#### 圆角说明

DiagnosisSummaryCard 使用 `Card variant="elevated"`，**无圆角**，与通用 Card 保持一致。

**设计原则**：DiagnosisSummaryCard 是"信息容器"而非"独立卡片"，使用无圆角以融入页面整体布局。

#### 完整示例

```tsx
<DiagnosisSummaryCard
  diagnosis={{
    narrative_type: "升级流",
    arc_type: "白手起家",
    protagonist: "林天",
    value_logic_type: "善义有价值",
    topic_labels: ["修仙", "成长", "热血", "友情", "冒险"],
  }}
  novelId={novelId}
/>
```

### 4.15 业务卡片组件分类规范

业务卡片组件分为两类，遵循不同的圆角规则：

#### 类型 A：容器型卡片（无圆角）

| 组件 | 圆角 | 使用场景 |
|------|------|---------|
| Card（default / elevated） | 无 | 通用容器，融入页面布局 |
| DiagnosisSummaryCard | 无 | 信息容器，嵌入页面 |

**设计原则**：容器型卡片是"页面布局的一部分"，使用无圆角以避免视觉割裂。

#### 类型 B：独立型卡片（12px 圆角）

| 组件 | 圆角 | 使用场景 |
|------|------|---------|
| DimensionMiniCard | `rounded-xl` | 五维速览，独立展示 |
| ScoreOverviewCard | `rounded-xl` | 评分速览，独立展示 |
| NarrativeStructureBar | `rounded-xl` | 结构概览，独立展示 |
| NovelCard | 无（特殊设计）| 书籍比例，左侧装饰条 |

**设计原则**：独立型卡片是"可移动的内容单元"，使用圆角以增强视觉独立性。

#### 圆角选择规则

```
是否需要独立视觉单元？
  ├─ 是 → 使用 rounded-xl（12px）
  └─ 否 → 使用无圆角（融入布局）
```

**判断标准**：
- 如果卡片在页面中作为独立模块存在，与其他卡片并列展示 → 使用圆角
- 如果卡片作为页面布局的一部分，承载信息容器功能 → 使用无圆角

## 五、页面间联动

### 5.1 全局上下文

通过 Zustand `novelStore` 维护：

```typescript
interface NovelContext {
  currentNovelId: string | null;
  currentTaskId: string | null;
  setNovel: (novelId: string) => void;
  setTask: (taskId: string) => void;
}
```

所有子页面共享同一个 `novelId` + `taskId`，切换任务时所有页面数据自动刷新。

### 5.2 页面跳转关系

```
HomePage ──点击小说卡片──▶ NovelDetailPage
                           │
                           ├──点击曲线缩略──▶ CurvesPage
                           ├──点击角色卡片──▶ CharactersPage
                           ├──点击图谱入口──▶ GraphPage
                           ├──点击主题入口──▶ TopicsPage
                           ├──点击时间轴入口──▶ TimelinePage
                           └──点击诊断摘要──▶ DiagnosisPage

GraphPage ──点击节点──▶ CharactersPage（定位到对应角色）
TimelinePage ──点击节点角色──▶ CharactersPage
```

### 5.3 URL 状态同步

`task_id` 作为 URL 查询参数同步，确保页面可分享、刷新不丢失：

```
/novels/10960c77?task_id=a1b2c3d4
/novels/10960c77/curves?task_id=a1b2c3d4
/novels/10960c77/graph?task_id=a1b2c3d4
```

# 动态主题色系统设计

> **版本**: v1.0  
> **创建时间**: 2026-04-02  
> **定位**: 描述「一书一色」动态主题色系统的完整设计，包括种子色来源、HSL 派生算法、CSS 变量体系、深浅模式切换

---

## 一、设计理念

每本小说拥有独特的视觉身份——后端在诊断阶段为每本书生成一个**种子色**（`theme_color`），前端将这个单一十六进制色值转换为 HSL 色彩空间，通过数学运算派生出完整的色板，包括深色模式和浅色模式的所有色彩。

**核心优势**：
- 后端只需返回一个 `#RRGGBB`，前端开销为零（纯 CSS 变量 + 一次性 JS 计算）
- 深浅切换不需要额外接口调用，仅调整 L（亮度）和 S（饱和度）偏移系数
- 切换书籍时只需更新 CSS 变量根节点，所有组件自动联动

### 2.1 后端返回

  ...

**生成策略建议**（由后端诊断 prompt 引导 LLM 生成）：

| 小说类型/基调 | 建议色相范围 | 示例 |
|--------------|-------------|------|
| 仙侠/修仙 | 蓝紫色系 (220°-280°) | `#6C5CE7` |
| 玄幻/奇幻 | 琥珀金色系 (30°-50°) | `#D4A843` |
| 都市/现实 | 青灰色系 (180°-210°) | `#4A9E9E` |
| 悬疑/恐怖 | 深红暗色系 (340°-10°) | `#C0392B` |
| 言情/青春 | 粉玫色系 (320°-350°) | `#E84393` |
| 历史/军事 | 暗金铜色系 (20°-40°) | `#B8860B` |
| 科幻 | 冷青色系 (170°-200°) | `#00B4D8` |

### 2.2 兜底机制

| 场景 | 处理方式 |
|------|---------|
| 分析已完成，有 `theme_color` | 使用后端返回的种子色 |
| 分析未完成 / 无诊断数据 | 使用前端内置默认色 `#6366F1`（Indigo 500） |
| `theme_color` 格式非法 | 降级为默认色，控制台输出警告 |

## 三、HSL 派生算法

### 3.1 Hex → HSL 转换

```typescript
interface HSL {
  h: number; // 0-360
  s: number; // 0-100
  l: number; // 0-100
}

function hexToHSL(hex: string): HSL {
  const r = parseInt(hex.slice(1, 3), 16) / 255;
  const g = parseInt(hex.slice(3, 5), 16) / 255;
  const b = parseInt(hex.slice(5, 7), 16) / 255;

  const max = Math.max(r, g, b);
  const min = Math.min(r, g, b);
  const d = max - min;

  let h = 0;
  if (d !== 0) {
    if (max === r) h = ((g - b) / d) % 6;
    else if (max === g) h = (b - r) / d + 2;
    else h = (r - g) / d + 4;
    h = Math.round(h * 60);
    if (h < 0) h += 360;
  }

  const l = (max + min) / 2;
  const s = d === 0 ? 0 : d / (1 - Math.abs(2 * l - 1));

  return {
    h,
    s: Math.round(s * 100),
    l: Math.round(l * 100),
  };
}
```

### 3.3 图表配色补充说明

- **情绪/正负极性**相关的颜色（正面绿、负面红）使用**固定色值**，不跟随主题色，确保语义一致性
- **数据系列色**通过在种子色色相 H 上偏移 ±40°、±80° 生成，保证色彩和谐且可区分
- 深色模式下图表色的 L 值需 +10%，确保在暗色背景上有足够对比度

### 3.4 对比度安全校验

```typescript
/**
 * 计算两个 HSL 颜色之间的 WCAG 对比度
 * 要求：文字与背景的对比度 ≥ 4.5:1（AA级）
 * 如果不达标，自动调整文字色的 L 值
 */
function ensureContrast(foreground: HSL, background: HSL): HSL {
  const fgLum = relativeLuminance(hslToRgb(foreground));
  const bgLum = relativeLuminance(hslToRgb(background));
  const ratio = contrastRatio(fgLum, bgLum);

  if (ratio >= 4.5) return foreground;

  // 背景偏亮 → 文字加深，背景偏暗 → 文字提亮
  const adjusted = { ...foreground };
  if (bgLum > 0.5) {
    adjusted.l = Math.max(adjusted.l - 10, 5);
  } else {
    adjusted.l = Math.min(adjusted.l + 10, 95);
  }
  return adjusted;
}
```

### 5.2 Zustand 主题 Store

```typescript
// store/themeStore.ts
import { create } from "zustand";
import { persist } from "zustand/middleware";
import { generateThemePalette } from "@/lib/theme";

const DEFAULT_SEED = "#6366F1"; // Indigo 500

interface ThemeState {
  seedColor: string;
  isDark: boolean;
  setSeedColor: (hex: string) => void;
  toggleDark: () => void;
}

export const useThemeStore = create<ThemeState>()(
  persist(
    (set) => ({
      seedColor: DEFAULT_SEED,
      isDark: false,
      setSeedColor: (hex) => set({ seedColor: hex }),
      toggleDark: () => set((state) => ({ isDark: !state.isDark })),
    }),
    { name: "novel-viz-theme" }  // localStorage 持久化
  )
);
```

### 5.3 主题色应用 Hook

```typescript
// hooks/useNovelTheme.ts
import { useEffect } from "react";
import { useThemeStore } from "@/store/themeStore";
import { generateThemePalette } from "@/lib/theme";

export function useNovelTheme() {
  const { seedColor, isDark } = useThemeStore();

  useEffect(() => {
    const palette = generateThemePalette(seedColor);
    const vars = isDark ? palette.dark : palette.light;
    const root = document.documentElement;

    // 批量更新 CSS 变量
    Object.entries(vars).forEach(([key, value]) => {
      root.style.setProperty(key, value);
    });

    // 切换 dark class
    root.classList.toggle("dark", isDark);
  }, [seedColor, isDark]);
}
```

### 5.4 使用流程

```
用户选择一本小说
    │
    ▼
前端请求 GET /api/novels/{novelId}/diagnosis?task_id=xxx
    │
    ▼
从响应中取出 theme_color（如 "#4A90D9"）
    │
    ▼
调用 useThemeStore.setSeedColor("#4A90D9")
    │
    ▼
useNovelTheme() 自动触发：
  1. generateThemePalette("#4A90D9") → 生成 light/dark 两套色板
  2. 根据 isDark 选择对应色板
  3. 批量写入 CSS 变量到 :root
    │
    ▼
所有使用 TailwindCSS 主题色类名的组件自动更新颜色
（如 bg-primary, text-text-secondary, border-border 等）
    │
    ▼
ECharts 图表通过读取 CSS 变量获取 chart-1 ~ chart-5 配色
```

// lib/echarts-theme.ts

/**
 * 从 CSS 变量中读取当前主题色，生成 ECharts 颜色数组
 */
export function getEChartsColors(): string[] {
  const root = document.documentElement;
  const getVar = (name: string) => {
    const value = getComputedStyle(root).getPropertyValue(name).trim();
    return `hsl(${value})`;
  };

  return [
    getVar("--chart-1"),
    getVar("--chart-2"),
    getVar("--chart-3"),
    getVar("--chart-4"),
    getVar("--chart-5"),
  ];
}

/**
 * 获取情绪相关的固定配色
 */
export function getEmotionColors() {
  const root = document.documentElement;
  const getVar = (name: string) => {
    const value = getComputedStyle(root).getPropertyValue(name).trim();
    return `hsl(${value})`;
  };

  return {
    positive: getVar("--chart-positive"),
    negative: getVar("--chart-negative"),
    neutral: getVar("--chart-neutral"),
  };
}

# 中文网络小说量化分析系统用户手册

## 一、作品简介

中文网络小说量化分析系统用于对单部中文网络小说进行结构化分析与可视化展示。系统围绕叙事结构、情绪与节奏、角色、人物关系、主题与诊断等维度生成分析结果，并通过 Web 页面统一展示。

当前系统的使用特点如下：

- 无需登录即可使用。
- 当前上传入口支持 `.txt` 文本文件。
- 单个上传文件大小上限为 10 MB。
- 支持同一部小说创建多个分析任务，便于重新分析、对比不同结果与保留历史记录。

---

## 二、使用前准备

在开始使用前，请先确认系统已经由部署者完成安装并成功启动。

当前系统有两种常见访问方式：

- 源码运行模式：
  - 前端页面通常访问 `http://localhost:5173`
  - 后端接口文档通常访问 `http://localhost:8000/api/docs`
- Docker 运行模式：
  - 前端页面通常访问 `http://localhost:18080`
  - 后端接口文档通常访问 `http://localhost:18080/api/docs`

如果你只能使用作品功能，而不负责部署环境，可直接向部署者索取可访问的前端页面地址。

## 三、系统入口与页面结构

系统当前以 Web 前端为主入口。页面结构分为首页和小说详情页两层。

### 3.1 首页

首页用于管理小说列表，主要操作包括：

- 上传新的小说文本
- 查看已有小说
- 按书名、作者或文件名搜索
- 按最近上传、书名、文件大小排序
- 删除小说

当系统中还没有小说时，首页会提示用户先上传小说。

### 3.2 小说详情页

进入某一本小说后，系统会展示该小说对应的分析工作区。当前侧边导航包括以下页面：

- 仪表盘
- 情绪/节奏曲线
- 角色分析
- 人物关系图谱
- 主题分布
- 叙事时间轴
- 诊断报告

这些页面都依赖当前选中的分析任务。如果没有可用任务，页面会提示先开始分析。

---

## 四、标准使用流程

建议按照“上传小说 -> 创建分析任务 -> 等待完成 -> 查看结果”的顺序使用系统。

### 4.1 上传小说

在首页点击“上传小说”后，会打开上传对话框。当前上传规则如下：

- 支持拖拽上传，也支持点击选择文件。
- 支持一次选择多个文件。
- 当前仅支持 `.txt` 格式。
- 单个文件大小不能超过 10 MB。

上传成功后，首页小说列表会自动刷新，新小说会出现在列表中。

### 4.2 打开小说详情页

在首页点击某一本小说后，会进入该小说的详情页。第一次进入时，如果还没有分析任务，页面会显示“尚未分析”的提示，并提供“开始分析”按钮。

### 4.3 创建分析任务

在小说详情页中，可以通过以下两种入口创建任务：

- 点击页面中的“开始分析”
- 点击页头区域的“新建分析”或“新建分析任务”

系统会为当前小说创建一个新的分析任务，并立即开始执行。任务创建成功后，页面会自动切换到该任务上下文。

### 4.4 查看任务进度

任务运行期间，仪表盘页会显示“分析进行中”面板，其中包括：

- 当前阶段进度
- 实时阶段信息
- 流式输出内容
- “停止分析”按钮

当前前端会展示的主要阶段名称包括：

- 预处理
- 标注分析
- 数据聚合
- 主题建模
- 诊断报告

如果任务执行时间较长，建议优先观察进度面板，而不是频繁刷新页面。

### 4.5 查看分析结果

任务完成后，系统会自动刷新相关数据，此时可以通过左侧导航查看各类结果。

## 五、各功能页面说明

### 5.1 仪表盘

仪表盘用于快速浏览本次分析的核心结果，是进入某个任务后的默认页面。该页面通常会集中展示：

- 诊断摘要
- 关键评分概览
- 维度摘要卡片
- 叙事结构概览
- 曲线预览

如果任务尚未完成，仪表盘会优先显示进度，而不是展示不完整结果。

### 5.2 情绪/节奏曲线

该页面用于查看分块级别的情绪与节奏变化，适合观察：

- 情绪强弱变化
- 节奏起伏
- 章节推进是否平稳
- 高波动区段是否集中

如果需要从宏观上把握作品节奏，这一页通常是最直接的入口。

### 5.3 角色分析

角色分析页用于查看人物相关统计信息，适合了解：

- 主要人物出现频率
- 角色功能分布
- 叙事关注度
- 角色在文本中的总体活跃程度

### 5.4 人物关系图谱

人物关系图谱页用于查看人物之间的关系网络及其变化。该页面更适合分析：

- 主要人物之间的关系结构
- 关系强弱与变化趋势
- 关键关系事件
- 图谱中的核心节点

图谱页与时间轴页之间支持围绕任务上下文进行联动查看，因此在分析人物关系演化时，通常建议与时间轴页结合使用。

### 5.5 主题分布

主题分布页用于查看作品中的主题结果，适合了解：

- 当前任务抽取出的主题项
- 各主题相对权重
- 主题关键词集合

这一页更偏向内容层面的概览，而不是情节层面的结构分析。

### 5.6 叙事时间轴

叙事时间轴页用于查看事件在叙事过程中的展开情况。该页面适合观察：

- 关键节点的时序分布
- 不同阶段的推进节奏
- 事件层级与结构组织
- 特定节点与图谱事件之间的关联

如果希望从“故事是怎样一步步展开的”这个角度理解文本，时间轴页通常比图谱页更直观。

### 5.7 诊断报告

诊断报告页用于查看更高层的综合判断结果，常见内容包括：

- 风格标签
- 类型标签
- 叙事弧线判断
- 价值逻辑说明
- 角色焦点结构
- Setup 台账

当任务缺少当前版本要求的完整诊断结构时，系统会明确提示“需要重新分析”，而不会继续把旧结果当作正常结果展示。

## 六、任务管理说明

### 6.1 任务列表与任务切换

每本小说都可以拥有多个分析任务。页头中的任务下拉区域用于管理这些任务。

在任务列表中，可以看到：

- 任务编号的前 8 位
- 当前任务状态
- 创建时间
- 与该任务相关的操作按钮

点击某个任务后，当前页面会切换到对应任务的结果视图。

### 6.2 任务状态说明

当前系统中的任务状态主要包括：

- `pending`：任务已创建，等待执行或可继续执行
- `running`：任务正在执行
- `cancelling`：任务正在取消
- `cancelled`：任务已取消
- `completed`：任务已完成，可以查看结果
- `failed`：任务执行失败，需要检查原因

### 6.3 可执行的任务操作

根据任务状态不同，系统支持以下操作：

- 新建分析任务
- 选择某个已有任务作为当前任务
- 停止正在执行的任务
- 继续执行 `pending` 或 `failed` 的任务
- 删除任务

如果某个任务已经不再可信或结果过旧，建议直接新建任务重新分析。

## 七、结果阅读建议

如果是第一次使用本系统，建议按以下顺序阅读结果：

1. 先看仪表盘，快速理解本次分析的大致结论。
2. 再看情绪/节奏曲线，判断文本推进节奏是否稳定。
3. 接着查看角色分析与人物关系图谱，理解人物结构。
4. 然后查看叙事时间轴，把事件推进与人物关系变化对应起来。
5. 最后阅读诊断报告，获取更高层的综合判断。

这种顺序比较适合从“先总览、再展开、后归纳”的方式理解作品。

## 八、常见问题

### 8.1 首页无法上传文件

请优先检查以下内容：

- 文件是否为 `.txt` 格式
- 单个文件是否超过 10 MB
- 后端服务是否已正常启动

### 8.2 页面可以打开，但小说列表为空

常见原因包括：

- 当前系统中确实还没有上传任何小说
- 后端接口未正常工作，导致列表读取失败
- 前端访问地址与后端服务地址不匹配

### 8.3 可以上传小说，但无法开始分析

常见原因包括：

- 分析任务创建接口不可用
- 后端运行正常，但外部模型服务未配置完整
- 数据库或模型服务连接异常

### 8.4 任务一直没有完成

建议按顺序检查：

- 进度面板是否仍在更新
- 后端日志是否报错
- 模型服务是否可访问
- 数据库是否正常运行

如果长时间没有任何进度变化，可先停止任务，再重新创建或继续分析。

### 8.5 页面提示需要重新分析

这通常表示当前任务的结果不再满足当前版本页面的读取要求。出现这种情况时，建议：

- 不再继续依赖旧任务结果
- 直接为该小说新建一个分析任务
- 等新任务完成后再查看图谱、时间轴或诊断页

### 8.6 某些结果页无法打开，但其他页面正常

这通常说明：

- 当前任务尚未完成，结果尚不可读
- 当前结果缺少特定页面所需的数据
- 当前任务需要重新分析

遇到这种情况时，优先回到仪表盘与任务状态区域确认当前任务状态。

# Virtual Environment Implementation Plan

## Goals

- Use project-local `.venv` only.
- Avoid system-level Python package drift.
- Standardize daily commands behind one script entrypoint.

## Bootstrap Once

Run from repository root:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 setup
```

This command:

- creates `.venv` if missing
- runs `uv sync --all-groups` for runtime + dev dependencies

## Daily Commands

```powershell
# API
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 api --reload --port 8000

# CLI
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 cli preprocess --source <file> --db <db_path>

# Tests
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 test -v

# Lint + type check
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 lint src tests scripts
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 typecheck src tests scripts
```

## Interpreter Verification

```powershell
uv run python -c "import sys; print(sys.executable)"
```

The path should point to `<repo>/.venv/Scripts/python.exe`.
